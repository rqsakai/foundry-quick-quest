# QuickQuest glossary — English → Português (Brasil)

One word per concept, used everywhere: sheets, chat cards, dialogs, rulebook, tooltips.
`languages/pt-BR.json` follows this table. **Status: draft** — translated by the implementer,
awaiting the owner's sign-off. Change a term here first, then in the language file.
